# Grahmir's Dungeon — расписание клуба

Статический сайт (`index.html`, без сборки) на Vercel; данные отдаёт Apps Script
(`apps-script/Code.gs`) из Google Таблицы клуба. Подробности — в README.

## Логотипы игровых систем

- Каждая система в названии игры получает значок из `assets/systems/`, список — `SYSTEMS` в `index.html`.
- Когда в таблице появляется новая система без значка, нарисуйте значок сами, не спрашивая:
  простой SVG 24×24 в духе системы (как щупальце для Call of Cthulhu, анкх для Vampire),
  один-два цвета, хорошо читается в 16 px на тёмном фоне. Затем добавьте строку в `SYSTEMS`.
- Если клуб присылает официальный логотип — упростите его до узнаваемой части
  (как звезда Fabula Ultima или буква G у Grimwild) и замените им нарисованный значок.
