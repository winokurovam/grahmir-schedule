# Шпаргалка: как управлять сайтом самой

Сайт: https://grahmir-schedule.vercel.app

## 1. Всё, что меняется через таблицу

Большую часть сайта код трогать не нужно: правите таблицу, и сайт подхватывает
изменения при следующем открытии страницы.

| Что сделать | Как в таблице |
|---|---|
| Освободить слот | залить ячейку **бирюзовым** |
| Отменить игру (слот станет свободным) | залить ячейку **красным** |
| Открыть набор на игру | залить **розовым**, в ячейке время, игра и мастер |
| Прикрепить пост о наборе | правый клик по розовой ячейке → **Вставить примечание** → вставить ссылку `t.me/…` |
| Набор есть, а поста пока нет | просто розовая ячейка без примечания; на сайте будет «Скоро пост о наборе» |
| Закрыть набор (все набрались) | залить **голубым** или **зелёным** (зелёный добавляет пометку «набор закрыт») |
| Вернуть набор, если кто-то слился | снова залить **розовым**; ссылка из примечания вернётся сама |
| Постоянная кампания | **голубая** ячейка: «19:30-23:30 Название игры Мастер» |
| Аренда | **оранжевая**; на сайте не показывается |
| Новая неделя | скопировать блок недели целиком: строка с днями, строка с датами, комнаты |
| Новая комната | добавить её строки «ДЕНЬ» и «ВЕЧЕР» в блок недели |

Важно:
- Пишите систему в названии игры: «Call of Cthulhu Beksultan», а не просто «Beksultan», иначе у игры не будет значка.
- Нужно именно **примечание**, а не комментарий: комментарии с обсуждениями сайт не видит.
- Не удаляйте ячейку целиком (клавишей Delete), если хотите сохранить ссылку на пост: вместе с ячейкой удалится и примечание.
- Если расписание закончилось, на сайте появится «Мы ещё не обновили расписание, потерпите чуть-чуть».

## 2. Как поправить файл на GitHub прямо в браузере

1. Откройте https://github.com/winokurovam/grahmir-schedule/blob/main/index.html
2. Нажмите карандаш ✏️ (**Edit this file**) справа вверху.
3. Найдите нужное место: **Ctrl+F** (на Mac **Cmd+F**) и вставьте фразу из таблицы ниже.
4. Поправьте текст, **не трогая кавычки и запятые вокруг него**.
5. Нажмите **Commit changes…** → ещё раз **Commit changes**.
6. Через минуту-две обновите сайт. Vercel выкладывает изменения сам.

### Настройки

Все настройки лежат в одном блоке, найдите `Настройки: меняйте только этот блок`.

| Что поменять | Найдите строку | Пример |
|---|---|---|
| Сколько игроков нужно | `PARTY_SIZE: 'от 4 до 6'` | `PARTY_SIZE: 'от 3 до 5'` |
| Ник администратора | `TELEGRAM_USERNAME: 'Winesmoker_M'` | без `@` |
| Название клуба (в подвале сайта) | `CLUB_NAME: "Grahmir's Dungeon"` | кавычки здесь двойные из-за апострофа, оставьте их |
| На сколько дней вперёд показывать | `MAX_DAYS: 21` | только число |

`API_URL` не трогайте: это связь сайта с таблицей.

### Тексты на странице

| Где на сайте | Найдите в файле |
|---|---|
| Большой заголовок | `Свободные столы и наборы на игры` |
| Пояснение под заголовком | `Бирюзовые слоты свободны` |
| Заглушка в конце расписания | `Мы ещё не обновили расписание` (встречается 3 раза, меняйте везде одинаково) |
| Сообщение «нужен мастер» | `Хочу записаться на игру с вашим мастером` |
| Сообщение «свой мастер» | `Хочу забронировать слот` |
| Плашка про число игроков | `Обратите внимание` |
| Подсказка в окне набора | `Чтобы записаться, поставьте` |
| Карточка набора без поста | `Скоро пост о наборе` |

Внутри текста не ставьте символы `'` и `` ` ``: ими в коде обозначаются начало и конец
текста. Апостроф лучше писать как `’`. Кусочки вида `${whenText(slot)}` или
`${CONFIG.PARTY_SIZE}` не трогайте: на их место сайт сам подставляет дату и число игроков.

### Цвет значка комнаты

Найдите `--gem-amethyst: #B98AF0;` (рядом Topaz и Emerald) и поменяйте код цвета.
Подобрать код можно в любом «color picker» в интернете. Для новой комнаты попросите Claude.

## 3. Если что-то сломалось

Самый быстрый способ откатиться — вернуть прошлую версию в Vercel:
1. Откройте проект **grahmir-schedule** на https://vercel.com
2. Вкладка **Deployments**.
3. У предыдущей рабочей версии нажмите **⋯** → **Instant Rollback**.

Сайт сразу вернётся к прошлой версии. Потом можно спокойно разобраться,
что пошло не так в правке.

Если сайт пишет «Не получилось загрузить расписание», дело не в сайте, а в
скрипте Google: проверьте, что ссылка
https://script.google.com/macros/s/AKfycbyL11q4v5hJfJQy9L_2SXqNSrUxwK9CVfXgbNmjb5Wml3y03g0UwgkK9TOl0FIdOtyv/exec
открывается и показывает текст в фигурных скобках `{ … }`.

## 4. Как попросить помощи в обычном чате Claude

Если подписки нет, можно работать через бесплатный чат на https://claude.ai:

1. Напишите, что хотите поменять, и вставьте нужный кусок `index.html`
   (лучше небольшой, вокруг нужного места, а не весь файл).
2. Можно начать так: «Это сайт расписания клуба, статический HTML. Вот кусок
   кода. Поменяй, пожалуйста, … и пришли исправленный кусок целиком».
3. Вставьте ответ на GitHub по шагам из раздела 2.

Для новых значков систем: пришлите в чат логотип или название системы и
попросите «нарисуй простой значок SVG 24×24, один-два цвета, для тёмного фона».
Файл значка кладётся в папку `assets/systems/`, а в `index.html` в список
`SYSTEMS` добавляется строка по образцу соседних, например:

```js
{ name: 'Mothership', logo: 'assets/systems/mothership.svg', match: /mothership/i },
```
