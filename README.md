# Grahmir's Dungeon — свободные столы

Страница показывает игрокам свободные слоты на ближайшие 7 дней. Данные берутся
из Google Таблицы. Нажатие на свободный слот открывает Telegram администратора
с готовым сообщением, например:

> Привет! Хочу записаться на слот в пятницу, 17 октября, с 18:00 до 22:00 (Большой стол).

```
index.html            сайт целиком; настройки — блок CONFIG в начале <script>
apps-script/Code.gs   скрипт для Google Таблицы: читает текст и цвет ячеек, отдаёт JSON
```

## Как устроена таблица

Один лист — один стол или зал. Название листа видно на сайте.

|               | Пн      | Вт | Ср      | Чт | Пт      | Сб | Вс |
|---------------|---------|----|---------|----|---------|----|----|
| 12:00–16:00   |         |    |         |    |         | ООО Ромашка |    |
| 18:00–22:00   | Альфа   |    | Бета    |    | Гамма   |    |    |

- В ячейке есть текст (название компании) — слот **занят**.
- Ячейка пустая — слот **свободен**.
- Ячейка залита **красным** — бронь отменена, на сайте слот **свободен**.
  Подходит любой оттенок красного, включая светло-красный.
- Лист, имя которого начинается с `_` (например, `_заметки`), на сайт не попадает.

Названия компаний на сайт не уходят: скрипт отдаёт только «свободно / занято».

Красный значит «отменено на ближайшую неделю». Когда отменённая дата прошла,
уберите заливку, и слот снова станет занятым.

## Подключение (один раз, минут 10)

1. Загрузите свой Excel-файл в Google Диск и откройте его как Google Таблицу
   (Файл → Сохранить как Google Таблицу). Цвета ячеек сохранятся.
2. В таблице: **Расширения → Apps Script**. Удалите всё, что там есть, вставьте
   содержимое `apps-script/Code.gs`, сохраните.
3. **Начать развёртывание → Новое развёртывание** → тип «Веб-приложение».
   - Запуск от имени: **я**
   - У кого есть доступ: **все**

   Нажмите «Начать развёртывание», разрешите доступ к таблице, скопируйте URL
   (заканчивается на `/exec`).
4. В `index.html` в блоке `CONFIG` впишите:
   - `API_URL` — скопированный URL;
   - `TELEGRAM_USERNAME` и `CLUB_NAME` уже заполнены (`Winesmoker_M`, Grahmir's Dungeon).
5. Выложите сайт: GitHub Pages (Settings → Pages → Deploy from branch → `main`)
   или Vercel.

Изменения в таблице видны на сайте сразу после обновления страницы.

Если поменяете код в Apps Script, сделайте **Управление развёртываниями →
изменить → Новая версия**, иначе будет работать старая версия скрипта.
