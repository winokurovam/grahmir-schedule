# Grahmir's Dungeon — свободные столы

Страница показывает игрокам свободные слоты и наборы на игры по датам из
Google Таблицы клуба. Нажатие на слот открывает Telegram администратора
(@Winesmoker_M) с готовым сообщением, например:

> Привет! Хочу записаться на свободный слот в воскресенье, 18 октября, с 18:00 до 22:00 (Amethyst).

> Привет! Хочу присоединиться к игре «Campaign Beksultan» в субботу, 17 октября, с 13:00 до 17:00 (Emerald).

```
index.html            сайт целиком; настройки — блок CONFIG в начале <script>
apps-script/Code.gs   скрипт для Google Таблицы: читает текст и цвет ячеек, отдаёт JSON
assets/               эмблема, логотип, иконки сайта
```

## Как читается таблица

Лист «Расписание», блоки по неделям один под другим:

| КОМНАТА  | ВРЕМЯ | ПОНЕДЕЛЬНИК | … | ВОСКРЕСЕНЬЕ |
|----------|-------|-------------|---|-------------|
|          |       | 12 октября  | … | 18 октября  |
| Amethyst | ДЕНЬ  |             | … | 13:00-17:00 D&D Campaign Ruslan |
|          | ВЕЧЕР | 19:00-23:00 Black Road D&D Campaign Ruslan | … | |
| Topaz    | ДЕНЬ  | …           |   |             |

Цвет ячейки:

| Цвет | На сайте |
|------|----------|
| красный | игра отменена, слот **свободен** |
| бирюзовый | слот **свободен** |
| розовый | **идёт набор**, видно название игры, можно присоединиться |
| синий, оранжевый и любой другой | **занято** (кампании, аренда) |
| без заливки и без текста | клуб в это время не работает, слота нет |

- Время слота берётся из текста ячейки (`19:30-23:30 …`). У пустой бирюзовой
  ячейки время берётся из других комнат в тот же день и то же время суток,
  а если их нет — из часов работы: будни 19:30–23:30, выходные 13:00–17:00
  и 18:00–22:00 (`WEEKDAY_TIME` и `WEEKEND_TIME` в `Code.gs`).
- Названия кампаний и арендаторов на сайт не попадают. Видны только названия
  игр, на которые идёт набор (розовые ячейки).
- **Пост о наборе.** Скопируйте ссылку на пост в Telegram (правый клик по посту →
  «Копировать ссылку») и вставьте её в примечание к розовой ячейке
  (правый клик → «Вставить примечание») или сделайте ссылкой сам текст ячейки
  (Ctrl+K). На сайте в окне записи появится кнопка «Пост о наборе».
  Комментарии с обсуждениями (через «+») скрипт не видит, нужно именно примечание.
  Из примечаний на сайт уходит только ссылка на Telegram, остальной текст — нет.
- Новую неделю добавляйте так же: строка с днями, строка с датами, комнаты.
  Сайт сам покажет все даты от сегодняшнего дня до последней в таблице
  (не дальше 21 дня).
- Новая комната подхватится сама. Цвет её значка на сайте задаётся в `ROOM_COLORS`
  в `index.html`.

## Подключение (один раз, минут 10)

1. Откройте таблицу клуба в Google Таблицах.
2. **Расширения → Apps Script**. Удалите всё, что там есть, вставьте содержимое
   `apps-script/Code.gs`, сохраните.
3. **Начать развёртывание → Новое развёртывание** → тип «Веб-приложение».
   - Запуск от имени: **я**
   - У кого есть доступ: **все**

   Нажмите «Начать развёртывание», разрешите доступ к таблице, скопируйте URL
   (заканчивается на `/exec`).
4. В `index.html` в блоке `CONFIG` впишите этот URL в `API_URL`.
5. Включите GitHub Pages: Settings → Pages → Deploy from branch → `main`.
   Сайт откроется по адресу `https://winokurovam.github.io/grahmir-schedule/`.

Изменения в таблице видны на сайте сразу после обновления страницы.

Если поменяете код в Apps Script, сделайте **Управление развёртываниями →
изменить → Новая версия**, иначе будет работать старая версия скрипта.
